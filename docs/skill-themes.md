# Скил «Темы» (named-темы, селектор, custom-пикер)

Устройство системы тем, правила добавления и грабли, которые уже ловили.
Реестр тем: `src/theme/theme.ts`, селектор: `src/components/ThemeSwitcher/`,
пикер произвольного цвета: `src/components/ColorPicker/`.

## 1. Архитектура

```
localStorage('theme') = 'yaru' | 'aurora' | 'midnight' | 'forest' | 'day' | 'sage'
localStorage('colorState') = { colorFull }   ← произвольный цвет пикера (custom)
                 │
    ┌────────────┴─────────────┐
    │ initTheme()              │ вызывается из NRadioContainer при монтировании:
    │ getTheme() → applyColors │ custom восстанавливает сам ColorPicker из colorState
    └──────────────────────────┘
                 │ смена темы
    setTheme(name) → localStorage + applyColors(THEMES[name])
                 + removeItem('colorState')   ← custom-цвет снимается
                 + window.dispatchEvent(THEME_EVENT 'nr-theme-change')
                 │
    компоненты слушают THEME_EVENT (селектор, всё, что читает CSS-переменные)
```

- `THEMES` — экспортированный реестр: `Record<имя, ColorsInterface>`. **Селектор строит
  список из `Object.keys(THEMES)`** — новая тема появляется в нём автоматически.
- `getTheme()`: если в `colorState` есть `colorFull` → `'custom'`; иначе сохранённое имя
  (белый список имён!) либо дефолт `'yaru'`.
- `applyColors()` ставит CSS-переменные на `document.documentElement` — весь UI красится
  через `var(--...)`.
- Цвета визуализатора и любые новые элементы читают переменные каждый кадр/рендер —
  смена темы подхватывается без подписок.

## 2. Палитра: смысл переменных (ColorsInterface)

| Переменная | Что красит |
|---|---|
| `--bg-color` | фон страницы; свотч темы в селекторе; треугольник play в лого/кнопке |
| `--second-bg-color` | карточки станций, шапка, плеер, dropdown меню |
| `--border-color` | разделители **и нелайкнутые звёзды** (`.like`) — выбор влияет на оба |
| `--current-color` | акцент: лого-эквалайзер, NRADIO, play-кнопка, планка текущей станции, активная тема/подложки в селекторе |
| `--positive-color` | версия+дата в меню, подписи станций («128 kbps · …»), лайкнутые звёзды |
| `--color` / `--item-color` / `--link-color` / `--visited-color` | текст (visited — посещённые ссылки) |
| `--error-bg/border/color` | тосты ошибок |
| `--shadow-color` | тени dropdown/оверлеев |

Шесть тем: **yaru** (графит+оранжевый), **aurora** (терминал Ubuntu), **midnight**
(индиго+серебро+орхидея), **forest** (хвоя+мята+лайм), **day** (светлая нейтральная),
**sage** (светло-зелёная, парная к forest).

## 3. Селектор тем (ThemeSwitcher)

- Выглядит как **обычный селект**: контрол «свотч + название текущей + CSS-стрелка ▾»,
  по клику — плоский список строк в ОДНОЙ общей рамке; текущая тема — мягкая подложка
  `color-mix(акцент 16%)` + галочка ✓; выбор сворачивает список.
- Свотч строки/контрола — **двухцветный кружок 18px**:
  `linear-gradient(135deg, фон 50%, акцент 50%)` — фон темы + цвет логотипа.
- Тема `custom` показывается в контроле со своим цветом (colorState.colorFull),
  в списке выбора её нет.
- Шрифт названий 25px (просьба пользователя), размеры фиксированные.

## 4. Custom-тема и пикер цвета

- ColorPicker пишет `colorState.colorFull` в localStorage и применяет цвета сам
  (setTheme при этом НЕ вызывается).
- `getTheme()` видит `colorState` → `'custom'`; буллет themes в AGENTS.md описывает,
  как определяется.
- Выбор любой named-темы в селекторе вызывает `setTheme`, который **удаляет
  `colorState`** — custom снимается автоматически. Сброс пикера возвращает named-тему.

## 5. Чек-лист «добавить тему»

1. Палитра в `THEMES` (theme.ts) — все 13 переменных; шапка-комментарий с описанием гаммы.
2. Имя добавить в `ThemeName` и в белый список `getTheme()` — иначе тема не переживёт
   перезагрузку.
3. Селектор подхватит тему сам (`Object.keys(THEMES)`); проверь лейбл (первая буква капсом
   делается автоматически).
4. Контрасты: на **светлых** темах `--current-color` и `--positive-color` — ТЁМНЫЕ
   (9-11px текст версии/подписей), звёзды-разделители читаются на белых карточках.
5. Проверка вживую: `localStorage.setItem('theme','имя')` + reload (в headless — сначала
   снять SW и кэши: старый бандл врёт о классах), скриншот списка + открытого меню.
6. Обновить буллет тем в AGENTS.md (список и hex-значения).

## 6. Грабли (все пойманы на живом приложении)

| Грабля | Симптом | Правило |
|---|---|---|
| dropdown меню absolute без ширины | список тем сворачивался в столбец | shrink-to-fit по контенту: у wrap/flex контейнера max-content схлопывается — селектору задать ЯВНУЮ ширину (250px / vwMax(244px)) |
| `flex: 1` (basis 0) на кнопках | при переносе каждая кнопка — отдельная строка | `flex: 1 1 auto` |
| vwMax в меню-контролах | на мобильном вьюпорте (≥640 CSS px) всё удваивается (шрифт 20px вместо 10) | селектор — фиксированные размеры без vwMax |
| Station и Header оба z-index 100 | плеер (позже в DOM) перекрывал dropdown меню, последняя строка обрезалась | Station z-index 90, шапка 100; dropdown внутри шапки — 210 |
| светлая тема с ярко-зелёным positive | версия/подписи нечитаемы | positive/акценты на светлом фоне — тёмные оттенки |
| имя темы без записи в getTheme() | тема слетает при перезагрузке | белый список имён обязателен |
| свотч = акцент | у новых тёмных тем точки сливаются | двухцветный фон+акцент, окантовка `inset` тёмная+светлая |

## 7. Как расширять

- **Больше тем** — см. чек-лист выше; реестр и селектор расширяемые без правки компонента.
- **Светлая/тёмная по системе** (`prefers-color-scheme`): добавить пару тем с авто-выбором
  при отсутствии сохранённого значения — не ломает ручной выбор.
- **Смена темы без мерцания** (SSR): initTheme зовётся на монтировании; если появится
  вспышка дефолтной темы — переносить applyColors в inline-скрипт в `<head>`.
- Селектор не должен знать про цвета пикера, кроме custom-случая (colorState.colorFull).
