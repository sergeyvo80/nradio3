# Скил «Живой мини-эквалайзер» (LiveEq)

Устройство, отладка и правила развития мини-эквалайзера «играющей» станции.
Компонент: `src/components/LiveEq/` (LiveEq.tsx + LiveEq.module.scss).
Полная механика Web Audio — см. `docs/skill-visualizer.md`.

## 1. Архитектура

```
LiveEq (mounted только пока станция воспроизводится)
        │
        ├─ getAnalyser()            — из visualizerEngine (синглтон)
        │                             AnalyserNode есть ТОЛЬКО у CORS-потоков:
        │                             они играют через routed <audio> в Web Audio графе
        ├─ getByteFrequencyData()   — спектр каждый кадр (rAF)
        └─ silent (все нули / нет аналайзера)?
              ├─ нет  → живой режим: лог-обход спектра → inline height полосок
              └─ да   → dead++ ; после 20 кадров молчания → псевдо-режим:
                        плавная анимация формулой псевдо-VU из Visualizer
```

- **Живой режим**: логарифмический обход спектра, как в Visualizer —
  `pow(i/BARS, 1.6) * usable`, верхняя граница `0.68` (выше у mp3 нет энергии),
  берётся max соседних бинов, минимум 0.08.
- **Псевдо-режим**: НЕ CSS-петля (жёсткий метроном выглядел чужеродно), а та же
  JS-формула псевдо-VU, что в Visualizer: басы тяжелее
  (`weight = 1 - i/BARS*0.55`), «дыхание» произведением двух синусов
  (частоты 0.017 и 0.003), пол — 0.06.
- **Сглаживание**: `last[i] += (target - last[i]) * 0.35` — полоски не дёргаются.
- Первые `SILENT_FRAMES = 20` кадров тишины высоты держатся как есть
  (буферизация живого потока — не «мёртвый граф»).

## 2. Где монтируется (общий компонент)

- **Список станций** — `StationSelectorItem.tsx`:
  `{isCurrent && isPlaying && <LiveEq />}` (без пропов, читает аналайзер сам).
- **Плеер** — `Station.tsx`, в `.actions` рядом со звездой:
  `{playerState === PlayerStateEnum.Playing && <LiveEq />}`.
- Условие монтажа обязательно: без игры поток в графе молчит → LiveEq уйдёт
  в псевдо и будет изображать эфир на паузе.

## 3. Стили (LiveEq.module.scss)

- 4 полоски `span`, цвет `--current-color`, размеры БЕЗ рамок/теней:
  высота контейнера 20.4px, полоски фикс. 4.3px (одинаковые на десктопе
  и мобильных — мобильная ширина намеренно НЕ через `vwMax`), зазор 3.6px.
- Мобильные высота/зазор — `vwMax()` (`main.$mob`), ширина — фикс.
- Дефолтные высоты nth-child (40/90/60/100%) видны в статике — reduced-motion.
- `@media (prefers-reduced-motion: reduce)`: `height: 40% !important`
  (перебивает inline-высоты от JS) + rAF-цикл в TSX вообще не стартует.

## 4. Отладка

| Симптом | Причина | Действие |
|---|---|---|
| Полоски всегда псевдо у CORS-станции | Граф молчит (см. скил визуализатора: страховка, crossOrigin) | Чинить корень — routing/watchdog, не LiveEq |
| Псевдо включается в начале игры CORS-потока | Буферизация = 20 кадров нулей | Норма: первые кадры высоты держатся, псевдо включится только после |
| «Полоски не в теме» | Цвет — CSS-переменная, меняется на лету | Ничего: `--current-color` читается браузером сама |
| Полоски на паузе продолжают анимироваться | LiveEq смонтирован без условия | Монтировать только при `Playing`/`isPlaying` |

Проверка в браузере (prod-локально `next start -p 3002`):
- живой режим: `li[class*=--current]` → `div[class*=eq] > span`, смотреть
  `s.style.height` (inline = живой), два среза с интервалом — высоты разные;
- псевдо-режим: станция без ACAO на GET (`drum-and-bass-bassdrive` — у Bassdrive
  ACAO отдаётся только с Origin-заголовком... нет: Bassdrive молчит даже с Origin;
  Hirschmilch/SomaFM/Psyndora отдают ACAO на GET) — inline пустой, высоты меняет JS.

Важно про CORS-пробу: `ACAO` у многих CDN отдаётся на GET с Origin и НЕ отдаётся
на HEAD/простой curl — проверять `curl -s -D - -o /dev/null -r 0-2000 -H "Origin: http://localhost:3002" <stream>`.
Поэтому почти весь каталог — в живом режиме; псевдо достаётся по-настоящему
глухим потокам.

## 5. Правила и подводные камни (не нарушать)

1. LiveEq **без пропов** — берёт `getAnalyser()` сам; не плодить дубли аналайзера.
2. Все высоты — **inline style из JS**; CSS держит только дефолт для статики.
   Не возвращать keyframes-анимацию: конфликтует с inline-высотами.
3. rAF-цикл в LiveEq крутится всегда при смонтированном компоненте (в т.ч.
   в псевдо) — поэтому монтаж строго по условию «реально воспроизводится».
4. `data.every(v => v === 0)` на живом эфире почти невозможен (шум > 0) —
   надёжный признак «графа нет».
5. Размеры полосок при изменении: десктоп и мобильная ширина фикс (px),
   мобильные высота/зазор через `vwMax()` — не вернуть `vwMax` на ширину
   (полоски в списке и плеере должны быть одинаковыми).
6. При изменении списка станций (`stations.json`) тестовые станции живого/
   псевдо-режима: живой — `psy-prog-hirschmilch`, `groove-salad-soma-fm`;
   псевдо — `drum-and-bass-bassdrive`.
